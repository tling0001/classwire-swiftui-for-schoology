# ClassWire App Review Demo Mode

ClassWire provides an interactive, local demonstration experience for review when a live Schoology account cannot be provided for legal or institutional security reasons.

## Demo credentials

- Username: tester@classwire.app
- Password: ClassWireDemo2026!

Enter these credentials through Sign in with my account. ClassWire recognizes this exact pair locally and presents a confirmation dialog explaining the demo. Choose Enter Demo to continue. No request is made to Schoology, and these credentials are not a real Schoology account.

## Available sample areas

The demo includes representative fictional sample data and local interactions for:

- Home and recent activity, including a local like toggle
- Courses and course sections
- Upcoming assignments and events
- Grades and grade summaries
- Calendar
- Messages and local message composition
- Groups and group sections
- Resources and local sample previews
- Profile

The sample assignment submission control, like toggle, resource review state, and message composition are local simulations. No message is delivered, no coursework is submitted, and no real grade or Schoology record is changed.

## Important App Review requirement

Apple's App Review Guidelines 2.1(a) allow a built-in demo mode in lieu of a demo account when legal or security obligations prevent providing an account, with Apple's prior approval. Apple also requires that the demo exhibit the app's full features and functionality.

This initial implementation is an interactive demonstration of the principal app areas, not a complete backend simulator. It does not reproduce every Schoology operation, LTI launch, upload, download, or server-side effect. Do not claim that it provides every production feature or rely on it as the only review path until Apple has approved the approach and the demo has been expanded and verified against the full production feature set. If Apple requires live service access, arrange an institution-authorized Schoology test account.
